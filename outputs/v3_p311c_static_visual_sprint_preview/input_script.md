# 用 Claude Code 写公众号三个月后，我发现它提升的不只是效率

用 Claude Code 写公众号三个月了。

一开始我只是想找个工具帮我写代码，结果用它做自媒体创作比写代码还顺手。

今天分享我怎么用 Claude Code 做自媒体创作，以及它怎么帮我提升了执行力和记忆力。

---


以前写一篇公众号文章是这样的。

先读书找灵感，1 小时。

判断选题值不值得写，30 分钟。

写初稿，2 小时。

改稿，1 小时。

配图排版，1 小时。

加起来至少 5 个小时，大部分时间消耗在「想」和「等灵感」上。

现在是这样的。

打开 Claude Code，说帮我分析这周的读书笔记，选个选题。

它分析完给我几个选项，我看哪个顺眼就选哪个。

说写，它根据我的 Obsidian 笔记和历史文章生成草稿。

说评分，它给我五维评分，告诉我哪里需要改。

从「想」到「发布」，大概 40 分钟。

不是 Claude Code 帮我写了文章，是它帮我把「想」和「等灵感」的时间压缩到了几乎为零。

---


你有没有这种感觉，读了很多书，记住了 10%，用到了 1%。

我也是这样，读的时候觉得都懂了，过几天全忘了。

Claude Code 帮我把这个问题解决了。

我所有读书笔记都在 Obsidian 里，它能读我的 Obsidian，知道我这周读了什么书、划了哪些线、写了什么感想。

当我问它「我这周读了什么」的时候，它不只能告诉我书名，还能告诉我每本书的核心观点、我的感想、以及这些观点之间有什么关联。

举个例子。

我问 Claude Code，「我这周读的内容里，有没有可以写选题的」。

它会读我这周的读书笔记，分析每个观点的「可写性」，给我几个选题建议，每个建议都附带「为什么值得写」的分析。

以前这个过程需要我自己花 1 小时「想」，现在 5 分钟搞定。

---


执行力最大的敌人是「开始」。

写文章最难的不是写，是开始写。

脑子里有一百个想写的选题，真正动笔的没几个。

Claude Code 把「开始」这件事变得极其简单。

以前我要「想好写什么」才能开始，现在只需要说「帮我写」，它就帮我写了。

当然，AI 写的不能直接用，还需要我改，但它帮我跨过了「开始」这个最大的障碍。

具体操作是这样的。

`帮我写一篇关于 XXX 的公众号文章，参考我这周的读书笔记，风格参考我之前写的 YYY 文章`。

它生成草稿，我改，发布。

从「有想法」到「有草稿」，可能只需要 10 分钟。

这个 10 分钟的跨越，是执行力最大的提升。

---


### 场景一，选题分析

每天早上我会让 Claude Code 分析这周的读书笔记，选几个值得写的选题。

`分析我这周的读书笔记，推荐 3 个公众号选题，每个选题给出选题理由和大概的写作角度`。

它会读我的 Obsidian 笔记，分析每个观点的「可写性」，给出选题建议。

我选一个顺眼的，直接开写。

### 场景二，草稿生成

选好选题之后，让 Claude Code 生成草稿。

`帮我写一篇关于 XXX 的文章，参考我这周的读书笔记和历史文章，风格参考我之前写的 YYY`。

它会读相关的笔记和历史文章，生成符合我写作风格的草稿。

草稿不能直接用，但作为初稿已经完成了 80% 的工作。

### 场景三，结构优化

草稿写完之后，让 Claude Code 帮我优化结构。

`帮我看看这篇文章的结构有没有问题，哪里可以调整让逻辑更顺畅`。

它会分析文章结构，指出哪里逻辑跳跃、哪里论证不够充分、哪里可以加深。

### 场景四，标题生成

写完文章之后，让 Claude Code 生成标题。

`帮我生成 5 个标题，参考我这篇文章的内容和风格，每个标题要有冲突感或结果感`。

它会生成 5 个标题建议，我选一个顺眼的，或者组合几个取长补短。

---


每天早上，我会跑这样一个流程。

第一步，让 Claude Code 分析这周的读书笔记，推荐选题。

第二步，选一个选题，让它生成草稿。

第三步，修改草稿，让它评分，根据评分调整。

第四步，让它生成标题。

第五步，发布。

这个流程大概 40 分钟，大部分时间是 AI 在跑，我只需要做决策和修改。

以前写一篇公众号文章要 5 个小时，现在 40 分钟搞定。

不是我变强了，是工具变了。

---


### 问 Claude Code 写的文章没有灵魂？

确实，AI 写的文章缺少个人体验和情感。

但草稿不需要有灵魂，草稿只需要有骨架和逻辑。

个人体验和情感是我改稿的时候加进去的，不是 AI 写的，是我写的。

AI 帮我完成了 80% 的基础工作，剩下的 20% 才是真正需要我投入的。

### 问这样写出来的文章同质化？

确实有可能，如果只是让 AI 写，风格会趋同。

解决方法是给 AI 足够的个人背景，让它学习你的风格。

`参考我这篇文章的风格`，`参考我之前写的 XXX`，每次都给出具体的参考文章。

它会学习你的写作风格，而不是输出一个通用的模板。

---


用了三个月 Claude Code 做自媒体创作，我最大的感受是，它帮我把「想」和「开始」这两件事变得极其简单。

以前写文章最难的是「想好写什么」和「开始写」，现在这两件事都可以交给 AI。

我只需要做两件事，选题和改稿。

选题，选 AI 给的建议里最顺眼的。

改稿，把 AI 写的改成我自己的语言。

这种工作流让我保持了稳定的输出，从每周一篇变成了每天一篇。
