# 装了删、删了装，我终于把 Claude Code 的正确安装方式摸清楚了

装了删，删了装，我装了大概七八遍才摸清楚 Claude Code 的正确安装方式。

一开始我也觉得，不就是装个工具吗，能有多难。

结果踩了一堆坑。

今天我把我踩过的坑和正确安装方式都整理出来，帮你一次搞定。

Mac 和 Linux，用官方方式就行。

Windows 建议先走 WSL2，再按 Linux 的方式装。

第一次运行需要登录，账号准备好，基本就能顺着跑起来。

这部分其实不是最重要的。

最值钱的是，Claude Code 真正强的地方，不是“会聊天”，而是它能把你的日常动作接成一条工作流。

我现在最常用的不是单个命令，而是几个稳定的技能：

- 代码审查
- Git 提交
- 功能开发
- 安全检查
- PR 审查
- 前端设计
- 迭代循环
- 学习模式

这些东西单独看都不稀奇。

但当它们串成一套以后，你会发现很多以前要反复来回折腾的事情，突然就能稳定下来。

比如我以前提交代码，要先看 diff、再写 message、再判断要不要 push。

现在这类动作，可以直接变成更顺手的流程。

对普通人来说，最难的从来不是“知道一个工具”。

最难的是把工具放进自己的流程里。

如果你只是装了 Claude Code，它只是一个工具。

但如果你把它接进代码审查、提交、安全检查、功能开发这些动作里，它就开始帮你省时间了。

这就是我今天最想讲的：

工具不是拿来收藏的，是拿来接流程的。

如果你也在装 Claude Code，或者你已经装了但还没接到自己的工作流里，这篇可以直接拿去对照。

先把正确安装方式搞定，再把几个最常用的技能接起来。

别再一遍遍装了删、删了装。

先让它真的为你干活。
